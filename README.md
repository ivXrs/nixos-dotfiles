# nixos dotfiles

> last reviewed: 2026-10-28 · [leer en español](./README_es.md)

personal nixos configuration managed as a flake. it is built from small `irene` modules that can be enabled on their own or grouped into suites.

## what's here

| path | purpose |
|------|---------|
| `flake.nix` | inputs and `nixosConfigurations`. |
| `hosts/*/` | host-specific imports, disk layout, hardware, and enabled modules. |
| `homes/*/` | per-user home-manager configurations. |
| `modules/nixos/` | reusable system modules under the `irene` namespace. top-level ones (`boot`, `network`, `nvidia`, ...) are imported by each host. |
| `modules/nixos/programs/` | one module per program, each with an `irene.programs.<name>.enable` option. |
| `modules/nixos/suites/` | groups of programs behind one `irene.suites.<name>.enable` option. |
| `modules/home-manager/` | reusable user modules under the `irene.home-manager` namespace. |
| `templates/module/` | starting point for new modules. |
| `install.sh` | installs a host from a nixos live iso. wipes a disk. |
| `CLAUDE.md` | conventions and rules for the ai that works on this repo. |
| `LICENSE.txt` | mit license. |

## hosts

| host | description |
|------|-------------|
| `roxas` | main machine. intel + nvidia hybrid graphics, all suites enabled. |
| `vm` | virtual machine for testing. |

### host layout

`hosts/<name>/default.nix` imports disko, the home-manager nixos module, `disko.nix`, `hardware.nix`, and `configuration.nix`. `configuration.nix` imports each top-level module it uses and sets the `irene.*` options. `hardware.nix` is generated by `nixos-generate-config`.

### modules and suites

modules are layered: a program module (`modules/nixos/programs/<name>`) → a suite (`modules/nixos/suites/<name>`) that enables a group of programs → a host that enables suites. a new program is enabled from a suite, not from the host.

a program module named `foo` exposes `irene.programs.foo.enable` and applies its configuration only when the option is true:

```nix
options.irene.programs.foo.enable = lib.mkEnableOption "foo";

config = lib.mkIf config.irene.programs.foo.enable {
  programs.foo.enable = true;
};
```

a suite named `bar` groups program modules behind one option, `irene.suites.bar.enable`.

to add a module, copy `templates/module/default.nix` and replace `namespace.module` with the real option path. modules are not auto-discovered: add the new one to the `default.nix` imports of its parent directory. the flake only sees files tracked by git, so `git add` new files before `nix flake check`.

### home-manager modules

home-manager is integrated as a nixos module, so `nixos-rebuild switch` applies both system and user configuration. user modules live in `modules/home-manager/`; their option path mirrors their path under that directory:

```nix
options.irene.home-manager.foo.enable = lib.mkEnableOption "foo";

config = lib.mkIf config.irene.home-manager.foo.enable {
  programs.foo.enable = true;
};
```

a module at `modules/home-manager/foo/` exposes `irene.home-manager.foo.enable`. enable modules in `homes/<user>/default.nix`:

```nix
irene.home-manager.foo.enable = true;
```

## why this setup

the host file stays small: it decides which capabilities to enable, while modules own the implementation. adding a program or service does not mean editing every host, and suites describe a machine by role instead of by package list.

disko keeps the disk layout in the repository, so partitioning is reproducible instead of a sequence of manual commands.

i do not write the code by hand. i design the logic, and the ai executes it.

## quick start

requires nix with flakes enabled.

### install

from a nixos live iso, with this repository available:

```bash
sudo ./install.sh [--disk /dev/disk/by-id/...] [host]
```

`host` defaults to `roxas`. if `hosts/<host>/disko.nix` contains `REPLACE-ME`, the installer shows a menu of whole disks and saves the chosen one in that file. **it wipes the selected disk.**

### update

on an installed system, from the repository root:

```bash
nix flake check
alejandra .
sudo nixos-rebuild switch --flake .#<host>
```

`nixos-rebuild switch` applies both the system and the home-manager configuration; no separate `home-manager switch` is needed.
